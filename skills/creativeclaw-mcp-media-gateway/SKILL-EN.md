## 🚀 Module 3: 4-Phase Turnkey Execution SOP

### Phase 01: Execution Step
- **Action:** Lock the customer and cost each generation: serve creators and 2-5 person teams who generate media inside Claude/ChatGPT, verify per-call upstream pricing, failure billing, concurrency, and commercial licenses, and publish a points price table with an explicit uncertain-margin note.

### Phase 02: Execution Step
- **Action:** Build the minimal MCP media gateway: implement a /generate endpoint with points accounts and deduction, a model routing table, brand-parameter injection, an upstream adapter layer, and automatic refunds on failure; prove it with curl self-tests.

### Phase 03: Execution Step
- **Action:** Close the points loop: sell points packs through a legitimate payment provider (benchmark: $10 = 1000 points, never expiring, 100 free points), charge Team monthly, log every deduction, auto-refund failed generations, and reconcile upstream bills against points revenue weekly.

### Phase 04: Execution Step
- **Action:** Cold-start through directories plus direct channels: list in Claude/ChatGPT and MCP directories, recruit 10-50 seed users with real generation examples, and build a direct website and community channel so the business is not single-threaded on directory ranking.
