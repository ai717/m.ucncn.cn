## 📁 模块二：绝密一手尽调档案与真实单位经济模型 (Unit Economics)

### 一手信源背景（2026-11-07 复核，数字与试跑一致）

- 卖家匿名，在 Reddit 发了店铺后台截图：一年 683 单，$30,062 收入，平均每周约 10 单。
- 卖的是老车仪表盘里固定屏幕与仪表的内饰件。只卖 3D 打印件 $25，全部成本扣完约赚 $20；卖带屏幕与线束的整机 $150，约赚 $60~65。
- eBay 零星每月再来约 $1,000，不稳定。
- 一年零广告，只在指定 Facebook 群组发帖。
- 打印机是为教孩子学技能买的，CAD 在 YouTube 上学的。封闭式耐热打印机约 $400 起。
- 选品方法：挑一个大家热爱的老机器，进它的 Facebook 群，看车主反复问什么件，就打印什么。

### 复制者单位经济模型

| 环节 | 数字 | 说明 |
| --- | --- | --- |
| 打印件售价 / 利润 | $25 / 约 $20 | 耗材每个件 $0.5~3 |
| 整机售价 / 利润 | $150 / 约 $60~65 | 含屏幕与线束适配器 |
| Etsy 费用 | 约 11~15% | 已含在利润测算里 |
| 订单量 | 每周约 10 单 | 原卖家一年零广告的水平 |
| **月利润** | **$500~$1,500** | 1~2 台打印机、6~12 个月后的稳健水平 |
| 启动成本 | $400+ | 封闭式耐热打印机 |
| 回本周期 | 7~14 天 | 出第一个件、装车测试通过即可上架 |

### 天花板在哪里

打印机工时就是上限。一台机器一天能打的件数固定，想放大只有三条路：加一台打印机、只卖 STL 文件、把整机比例做高。通用 3D 打印爆款已从约 14 英镑跌到约 4.5 英镑，不要碰。

## 💻 模块三：生产级极简核心工程源码 / 数据库架构

核心就一张算账表：输入你的售价、成本与每周单量，算出每周与每月利润、打印机占用小时数。下面的 Bash 脚本（用 awk 算小数）就是最小可用版本。

```bash
#!/usr/bin/env bash
# truck_parts_calc.sh — 老车 3D 打印件算账器
# 用法：bash truck_parts_calc.sh <打印件售价> <打印件利润> <整机售价> <整机利润> <每周单量> <整机占比 0-1> <单件打印小时>
# 示例：bash truck_parts_calc.sh 25 20 150 62 10 0.3 2.5
set -euo pipefail
if [ "$#" -ne 7 ]; then
echo "用法: bash truck_parts_calc.sh <件售价> <件利润> <整机售价> <整机利润> <每周单量> <整机占比> <单件小时>"
exit 2
fi
PART_PRICE=$1
PART_PROFIT=$2
KIT_PRICE=$3
KIT_PROFIT=$4
ORDERS=$5
KIT_SHARE=$6
HOURS_PER_PART=$7
awk -v pp="$PART_PROFIT" -v kp="$KIT_PROFIT" -v o="$ORDERS" -v ks="$KIT_SHARE" -v h="$HOURS_PER_PART" -v pprice="$PART_PRICE" -v kprice="$KIT_PRICE" 'BEGIN {
part_orders = o * (1 - ks)
kit_orders = o * ks
weekly_profit = part_orders * pp + kit_orders * kp
monthly_profit = weekly_profit * 4.33
weekly_hours = o * h
printf "每周单量: %.0f 单（打印件 %.1f + 整机 %.1f）\n", o, part_orders, kit_orders
printf "每周利润: $%.2f\n", weekly_profit
printf "每月利润: $%.2f\n", monthly_profit
printf "每周打印机占用: %.1f 小时\n", weekly_hours
if (weekly_hours > 100) print "提醒：每周占用超 100 小时，一台打印机已满负荷，先加机器再接单。"
else print "OK: 一台打印机负荷内。"
if (monthly_profit >= 500 && monthly_profit <= 1500) print "OK: 月利润落在 $500~$1,500 稳健区间。"
else print "注意：月利润超出 $500~$1,500 稳健区间，检查单量或占比假设。"
}'
```

自检命令：

```bash
bash truck_parts_calc.sh 25 20 150 62 10 0.3 2.5
# 应输出每周利润约 $326、每月利润约 $1,412、每周打印机占用 25 小时，并打印两行 OK
bash truck_parts_calc.sh 25 20 150 62 10 0.3 12
# 每周占用 120 小时，应打印满负荷提醒
```

## 📈 模块五：安全合规、防封防踩坑与冷启闭环 SOP

### 红线

1. **不要打印别人的 STL 文件拿来卖**：2025 年 6 月起 Etsy 要求 3D 打印件为卖家原创设计，卖别人的设计会被下架。必须自己画 CAD。
2. **车内不要用 PLA**：不耐热、不耐紫外线，夏天车里会变形。用 PETG 或 ABS。
3. **不要碰安全件，不要用品牌商标**：只做内饰小塑料件，刹车等安全件一律不碰，商标一律不用。
4. **不要照搬 $30,062**：那是卖家自报的 Reddit 截图转述，未审计。对外只讲“卖家自报”，不讲“已验证年入三万美金”。
5. **不要先买一堆打印机**：先一台跑顺、退换流程跑顺，再加机器。
