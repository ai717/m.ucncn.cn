## 核心设计要点
1. **打破狭隘思维禁锢**：搞钱不仅是软件或虚拟商品，覆盖【纯数字资产】、【软硬结合与轻制造】、【线下实体数字化线索】、【跨境地理套利与撮合】四大跨界板块；
2. **8 大真实可靠信源**：Acquire微型收购、Etsy/3D打印轻制造热榜、Reddit痛点求助社区、sweatystartup线下数字化案例、GitHub飙升黑马、X实名公开构建者、国内高复购合规轻资产、垂直冷门执业题库；
3. **四维客观量化打分**：AI 测算门槛友好度、见效速度、收益天花板与抗风险稳定性，按权重输出 0~100 综合推荐指数与 S/A/B 评级；
4. **纯净结构化输出**：严格输出匹配数据契约的 JSON 数组，方便一键入库或通过 Webhook 自动上线。
