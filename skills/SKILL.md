## 核心红线：金额真实性与中国市场实证校准法则（Anti-Exaggeration）

> ⚠️ **AI 必须牢记：搞钱实验室是严谨的客观尽调机构，绝不是打鸡血的创业培训班。**

在评估任何项目的预期现金流与收益时，**严禁使用营销号的夸大失真数据**（如动辄“月入十万”、“轻松日入过千”等口嗨）：

1. **真实国内市场购买力对齐**：
   - 国内 C 端虚拟商品/资料库：主流真实客单价为 **¥9.9 ~ ¥49**（超过 ¥50 转化率即剧烈下滑）；单月个人副业合理稳态利润区间通常在 **¥1,500 ~ ¥6,000 / 月**，优秀头部案例在 **¥8,000 ~ ¥20,000 / 月**。
   - 国内小 B / 同城技术代搭服务：单笔收费普遍在 **¥800 ~ ¥3,500**，每月稳定成单 1~4 单，合理月现金流在 **¥3,000 ~ ¥15,000**。
   - **严禁虚标**：凡是声称“小白零基础无需成本，首月即入数万元”的项目一律视为营销欺诈，直接降级或淘汰。
2. **海外出海项目务实折扣**：
   - 海外 Micro-SaaS 或 Chrome 插件：虽然计价为美元（如 $4.99/月），但必须扣除 LemonSqueezy/Stripe 手续费（约 5~8% + 每笔固定扣费）、API 调用 Token 成本以及获客流失率（Churn Rate 约 6~12%）。
   - 个人早期单兵作战的真实可达成区间：**$300 ~ $2,500 / 月**（折合人民币约 ¥2,000 ~ ¥18,000），切忌盲目套用海外大 V 的头部极端爆款数据。
3. **成本与时间沉没实打实核算**：
   - 必须将测试购买域名、服务器、API 额度、以及最重要的人工耗时客观列出；凡是需要每天重度投入 6 小时以上才能换取微薄收入的，门槛友好度打低分。

## 核心协议：三级去重与赛道防同质化法则 (Triple-Stage Deduplication)

> ⚠️ **AI 必须严格执行：绝不把去重留到上线时肉眼甄别！采前查重零浪费，采中去同质化保纯度。**

每次采集或撰写新商业案例前，必须严格通过以下三道去重漏斗：

### 1. 第一级：采前硬查重（Pre-Ingestion Dedup · 强制前置条件）
- **必须先检索**：在动笔编写任何代码或 JSON 前，必须通过 MoneyLab 实时去重索引（在线读取 `https://m.ucncn.cn/llms.txt` 或 `catalog.json`，或检查本地已收录项目库）进行前置查重；
- **查重靶标**：比对【竞品/产品名】、【官网或 GitHub URL】以及【计划分配的 URL Slug】；
- **处置机制**：
  - 若库内已存在该项目的剖析（例如已有同名 Chrome 插件或 Reddit 获客 Bot），**立即终止编写，杜绝 1 个 Token 的无效消耗**；
  - 若该项目有重大财报突破（如从 $1k MRR 跃升至 $10k MRR），只能作为已有项目的“最新财报追更”，绝不允许另立新卡片导致 Slug 冲突与 SEO 自残。

### 2. 第二级：采中同质化软去重（Thesis & Saturation Balance）
- **赛道密度监控**：关注库内各大原型的分布均衡度，严禁千篇一律产出相同逻辑的衍生品；
  - 库内若已有“Chrome 插件订阅”，除非新案例拥有颠覆性的客单价模型或完全不同的硬件/技术载体，否则判定为“同质化重复”予以淘汰；
  - **优先倾斜稀缺蓝海**：优先采写入库目前库内样本偏少的赛道（如：**软硬结合轻制造、线下实体获客数字化撮合、高客单海外联盟网络、冷门垂直执业题库**）。

### 3. 第三级：入库与构建脚本自动化校验门禁 (Build-Time Assertion)
- **CI/脚本硬拦截**：`money/scripts/generate_landing_pages.js` 与合流工具在编译前自动执行唯一性断言：
  - 发现重复 `id` 或重复 `slug` 时，**控制台红色报错并强制中断编译**，杜绝任何重复或脏数据部署上线。

## 一、 六大核心商业原型自适应路由（杜绝模板化套用的核心机制）

每次尽调新项目时，**必须首先判定其商业原型**，并白手定制该原型专属的落地资产。**严禁把单一项目的物料（如 Reddit 监听代码、冷发邮件模板）生搬硬套到其他不同形态的商业项目中**：

```
                                [新项目尽调输入]
                                       │
          ┌──────────────┬─────────────┴─────────────┬──────────────┬──────────────┐
          ▼              ▼                           ▼              ▼              ▼
    【原型 A】       【原型 B】                  【原型 C】       【原型 D】       【原型 E】
   B2B 获客监听    客户端浏览器扩展            企业 AI 封装服务   数字化虚拟资产   微型资产并购转手
  (Reddit/Twitter) (Chrome Extension)         (Shopify/RAG)       (Notion/小红书)  (Acquire.com)
```

1. **原型 A：B2B 获客与强意向信号监听引擎 (Outbound & LeadGen)**
   - 核心机制：在潜在买家公开抱怨竞品或寻求替代工具的瞬间捕获信号并执行精准触达；
   - 专属落地资产：目标社区画像 + 三阶意向关键词 + 免 API 自愈监听脚本 + 0~100 分量化评分 Prompt + 3 轮冷发邮件追击序列。
2. **原型 B：客户端实用工具与浏览器插件 (Client-Side & Browser Extensions)**
   - 核心机制：依靠 Chrome Web Store (CWS) 庞大自然搜索，零服务器云成本解决高频单点痛点；
   - 专属落地资产：Manifest V3 极简核心架构 + LemonSqueezy/Stripe 离线许可校验 + CWS 商店 SEO 标题与长尾词布局 + 合规审核免拒声明。
3. **原型 C：垂直行业 AI 封装与企业私域服务 (AI Wrappers & B2B Solutions)**
   - 核心机制：传统中小企业缺乏 AI 研发能力，愿为“减少客户流失、提高转化率”支付高搭建费与月度维护费；
   - 专属落地资产：行业客服/小语种本土化核心 Prompt 链 + Dify/FastGPT 编排 DSL 导出 + 本地 RAG 向量防幻觉方案 + 交付合同与月度 SLA 模板。
4. **原型 D：高毛利数字化虚拟资产与模板 (Pure Digital Assets & Notion)**
   - 核心机制：一次制作终身零边际成本复购，切入欧美高意向市场或国内青年情绪疗愈刚需；
   - 专属落地资产：Notion 核心商业数据库架构图 + 小红书/Etsy 爆款视觉卡片设计提示词 + 面包多/Gumroad 自动化发卡与私域导流 SOP。
5. **原型 E：微型资产并购、翻新与转手 (Micro-SaaS Flipping & Acquire.com)**
   - 核心机制：收购或快速开发具有微弱正现金流 ($300~$800 MRR) 的半成品工具，优化关键指标后按 20~30 倍月倍数快速退出；
   - 专属落地资产：Acquire.com 挂牌转让 Memorandum 简报 + 降低 Churn 流失率的挽留机制 + 资产交割审查清单 (Due Diligence Checklist)。
6. **原型 F：软硬结合、小众配件与个性化轻制造 (Physical + Digital POD & 3D-Printing)**
   - 核心机制：切入原厂停产/冷门维修的窄口子（如老车绝版件、复古外设、工业卡扣），以“指定车型/指定设备/指定件”的原创设计避开通用爆款内卷，靠垂直车友群与 Etsy/eBay 高毛利变现；
   - 专属落地资产：原创 CAD 建模与装车实测规范 + 耐热工程耗材（PETG/ABS）切片与打印机小时数精算 + 真实车友群非广告真诚交流与发货退换 SOP。
7. **原型 G：冷门垂直执业资格认证高客单题库与冲刺包 (Niche Certifications & Exam Cram Vaults)**
   - 核心机制：欧美特种行业从业考证刚需（如 FAA Part 107 无人机、EPA 608 制冷剂、海事特种操作），自建静态题库自测站，高意向流量通过 Stripe/Gumroad 买断即走；
   - 专属落地资产：题库去重与自测脚本 + 考点高频记忆闪卡 Prompt + 静态答题评分引擎 + 考前 72 小时冲刺包落地页。

## 三、 四大一票否决过滤网与全站去重指纹库（去伪存真与排重门禁）

在甄选入库项目时，强制执行以下 4 道生死把关 + 1 道去重排斥门禁，任一不合格坚决淘汰：

### 1. 四大一票否决规则
1. **白嫖伪需求过滤**：人人叫好但毫无真金白银掏钱意愿的自嗨玩具，坚决淘汰；
2. **大厂踩踏过滤**：需求将在 3 个月内被 GPT / Claude / 微信官方系统原生功能直接覆盖的，坚决淘汰；
3. **黑灰产与合规风险过滤**：涉及违规爬虫、黑产引流、侵权仿冒、跨境欺诈的，零容忍坚决淘汰；
4. **营销割韭菜与夸大造假过滤**：核心商业模式本质是“靠卖教别人赚钱的课来赚钱”，或收益数字严重夸大失真的，坚决淘汰。

### 2. 全域动态查重与去撞车协议（差异化甄别法则 · 允同模式/重切口差异）

> 💡 **核心排重标准（甄别差异化，严禁机械化一刀切）**：  
> 我们的去重**绝不是“绝对不重复商业模式”**。经过市场验证的经典商业原型（如浏览器插件、B2B意向监听、特种考试题库、数字化资产）往往具有长期复利。
> **完全一样的同款产品坚决排除；但如果商业模式几乎相同，只要解决的垂直场景、痛点、目标客群或具体产品有明确差异，依然坚决采纳！**
>
> - ❌ **坚决排斥的「完全克隆」**：
>   - 相同的对标产品、完全相同的切入点与客群（如：库内已有 FAA 无人机题库，又提报完全一样的 FAA 无人机题库；已有 Reddit SaaS 意向监听，又提报几乎一模一样的 Reddit SaaS 意向监听）；
> - ✅ **坚决鼓励的「同模式不同细分赛道 / 微创新」**：
>   - **同样做 Chrome 插件**：已有针对单点小工具的插件，依然可以立项“针对 Etsy 卖家的标签挖掘插件”或“针对 LinkedIn 招聘的轻量线索插件”；
>   - **同样做特种考前题库**：已有无人机执照，依然可以立项“EPA 608 制冷技术员高薪准入题库”或“CDL 商业卡车司照冲刺自测”；
>   - **同样做意向信号监听**：已有 Reddit SaaS 论坛监听，依然可以立项“Twitter/X 跨境出海找网红/找摄影师需求监听”；
>   - **评判准则**：只要该项目在特定受众中有**独立且真实的买家池、独立的客单价与差异化痛点**，就是优质的新蓝海！

## 四、 AI 端四维量化打分模型（0 ~ 100 分）

AI 需根据以下 4 个维度客观打分（各 1~10 分），并严格代入公式计算总推荐值：

1. **门槛友好度 (Feasibility, 1~10分)**：资金、技术、供应链与人力依赖（10分：零资金/轻代码/单人；1分：重资产）；
2. **见效速度 (Velocity, 1~10分)**：动手到验证第一笔现金流的时间（10分：3~7天；7分：2~3周；3分：超3个月）；
3. **收益天花板 (Ceiling, 1~10分)**：月收益与规模化空间（务实评估：10分：月入$10k+或¥50k+且边际成本极低；6分：稳定副业¥3k~¥8k；3分：重体力低单价单）；
4. **抗风险稳定性 (Reliability, 1~10分)**：政策合规度与抗平台封号风险（10分：标准开放接口/正规平台；4分：擦边）。

### 综合推荐指数计算公式：
$$\text{Score} = \text{round}\left( \text{Feasibility} \times 2.5 + \text{Velocity} \times 2.5 + \text{Ceiling} \times 2.5 + \text{Reliability} \times 2.5 \right)$$
- **S 级（卓越推荐）**: $\ge 90$ 分（极高确定性、变现闭环成熟、启动轻快）
- **A 级（良好推荐）**: $80 \sim 89$ 分（需要特定技能或投入，收益稳定可观）
- **B 级（观察尝试）**: $70 \sim 79$ 分（存在特定门槛或竞争较激烈）
- **$< 70$ 分**: 坚决淘汰不予输出。
