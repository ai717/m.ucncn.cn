## 💻 模块三：生产级 FastAPI + LangChain 极简后端源码

以下代码演示了核心的 **“知识库混合召回 + 敏感信息防泄露 + 强制销售留资”** 接口：

```python
import os
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from langchain_community.vectorstores import Chroma
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain.prompts import PromptTemplate

app = FastAPI(title="Enterprise RAG Assistant API")

# 1. 向量数据库初始化
embeddings = OpenAIEmbeddings(
    openai_api_key=os.getenv("OPENAI_API_KEY"),
    openai_api_base=os.getenv("OPENAI_API_BASE", "https://api.openai.com/v1")
)
vector_db = Chroma(persist_directory="./knowledge_store", embedding_function=embeddings)

llm = ChatOpenAI(
    model="gpt-4o-mini",
    temperature=0.1,
    openai_api_key=os.getenv("OPENAI_API_KEY")
)

# 2. 企业专属反幻觉 Prompt 模板
RAG_SYSTEM_PROMPT = """你是一家知名专业机构的官方专属智能法律与商务顾问。
请严格基于以下【企业官方核准资料】回答用户问题：

【企业官方核准资料】：
{context}

【用户咨询内容】：
{question}

【执行铁律】：
1. 只能回答官方资料中明确记载的事实与业务流程；
2. 如果用户询问的内容在资料中未明确提及，或者涉及复杂定制价格，严禁胡编乱造，必须统一回复：“该问题涉及深度定制方案，建议由我们的资深顾问为您出具评估报告，您可以留下您的联系方式，稍后安排专人对接”；
3. 语气保持客观、专业、尊重，每轮对话结束时，适时提供 1 个让用户愿意留下联系方式（微信/电话）的明确价值锚点。
"""

prompt_template = PromptTemplate(
    template=RAG_SYSTEM_PROMPT, 
    input_variables=["context", "question"]
)

class QueryRequest(BaseModel):
    session_id: str
    query: str

@app.post("/api/chat")
async def chat_with_agent(req: QueryRequest):
    if not req.query.strip():
        raise HTTPException(status_code=400, detail="Query cannot be empty")

    # 检索最相关的 3 条上下文片段
    docs = vector_db.similarity_search(req.query, k=3)
    context_text = "\n\n".join([d.page_content for d in docs])

    chain = prompt_template | llm
    response = chain.invoke({"context": context_text, "question": req.query})

    return {
        "reply": response.content,
        "sources": [d.metadata.get("source", "FAQ") for d in docs]
    }
```

## 📄 模块四：B2B 商务合同与交付规格书 (SLA 范本)

在与企业主签约时，明确的职责边界是防止后期无休止改需求的唯一保障：

### 1. 核心交付物验收清单 (Deliverables)
1. **企业私有专属知识库 1 套**: 支持 PDF、Word、Excel 格式的产品手册与制度规章切片索引；
2. **多端交互入口 1 组**: 网页端右下角交互挂件 (Widget) + 微信服务号/小程序接入 API；
3. **管理后台与留资推送 1 套**: 客户留下姓名/电话后，实时推送到企业负责人的企业微信或邮箱；
4. **技术交接与使用培训 1 次**: 包含后台增删文档的 1 小时录屏与操作手册。

### 2. 知识产权与数据隐私承诺 (NDA)
- 明确约定：企业提供的所有客户资料与商业机密归企业所有，部署在企业专属私有环境或隔离云空间，开发者不得将其用于公开大模型训练。
