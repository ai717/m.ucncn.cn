## 💻 模块三：生产级 Notion 核心数据库架构规范 (DB Schema)

以下为最畅销的 **“50/30/20 智能现金流与预算系统 (Smart Budget OS)”** 核心数据库设计，可直接导入 Notion：

### 1. 核心数据库一：`Accounts` (资金账户)
- **字段规范**:
  - `Account Name` (Title): 账户名称（如: Chase Checking, Amex Gold, Emergency Fund）
  - `Type` (Select): 借记卡 / 信用卡 / 储蓄 / 投资
  - `Starting Balance` (Number · Currency): 初始金额
  - `Current Balance` (Formula): `prop("Starting Balance") + prop("Total Income Rollup") - prop("Total Expense Rollup")`

### 2. 核心数据库二：`Transactions` (日常收支明细)
- **字段规范**:
  - `Item` (Title): 支出/收入名目
  - `Amount` (Number · Currency): 金额
  - `Date` (Date): 交易日期
  - `Type` (Select): 收入 (Income) / 必需支出 (Needs 50%) / 欲望支出 (Wants 30%) / 储蓄投资 (Savings 20%)
  - `Account` (Relation): 关联 `Accounts` 数据库
  - `Category` (Relation): 关联 `Categories` 分类数据库

### 3. 核心数据库三：`Monthly Budgets` (月度预算进度条)
- **超支警报自动化公式 (Formula)**:
```text
let(
  spent, prop("Actual Spent Rollup"),
  budget, prop("Target Budget"),
  percent, round(spent / budget * 100),
  if(
    spent > budget,
    "🚨 Over Budget by $" + str(round((spent - budget) * 100) / 100) + " (" + str(percent) + "%)",
    if(
      percent >= 90,
      "⚠️ Caution: " + str(percent) + "% used",
      "🟢 On Track: " + str(percent) + "% used"
    )
  )
)
```
