## 💻 Module 3: Production Notion Database Schema (50/30/20 Smart Budget)

### 1. Database 1: `Transactions`
- `Item` (Title): Expense or income name
- `Amount` (Number - Currency): Value
- `Date` (Date): Transaction timestamp
- `Type` (Select): Income / Needs (50%) / Wants (30%) / Savings (20%)
- `Account` (Relation): Linked to `Accounts` DB
- `Category` (Relation): Linked to `Categories` DB

### 2. Database 2: `Monthly Budgets` (Automated Over-Budget Alert Formula)
```text
let(
  spent, prop("Actual Spent"),
  budget, prop("Target Budget"),
  percent, round(spent / budget * 100),
  if(
    spent > budget,
    "🚨 Over Budget by $" + str(round((spent - budget) * 100) / 100) + " (" + str(percent) + "%)",
    if(percent >= 90, "⚠️ Caution: " + str(percent) + "%", "🟢 On Track: " + str(percent) + "%")
  )
)
```
