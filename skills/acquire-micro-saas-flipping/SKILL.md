## 💻 模块三：生产级独立可过户工程架构规范

在从第一天写代码开始，**必须确保该项目与你的个人资产彻底物理隔离**，否则在交割时将导致无法过户或隐私泄露：

### 1. 资产隔离四项硬指标
1. **域名与 DNS 隔离**: 单独注册在 Cloudflare 独立子账户或可一键转移的域名商（如 Namecheap / Porkbun）；
2. **认证与数据库隔离**: 使用 Supabase 独立 Project，禁止将多个项目共用同一个 Supabase Organization；
3. **支付网关隔离**: 单独为该项目开设一个 Stripe 关联账户 (Sub-account) 或独立 LemonSqueezy Store，支持一键更改商业主体法人；
4. **Git 代码仓库清洗**: 核心 API Key（如 OpenAI, Resend, Supabase Service Role）绝不可硬编码在 Git 提交历史中，必须纯依赖环境变量 `.env`。

## 🤝 模块五：安全交割与 Escrow.com 资金闭环 SOP

1. **签署意向书 (Letter of Intent · LOI)**: 买卖双方锁定转让金额与 14 天排他审查期；
2. **开设 Escrow.com 并购托管**: 由买方将全额资金打入 Escrow 官方监管账户；
3. **分阶段资产交割**:
   - 阶段 1：向买方转移域名所有权（DNS 过户）；
   - 阶段 2：向买方授权 GitHub 仓库所有者权限；
   - 阶段 3：协助买方完成 Stripe 绑卡与环境变量重配置；
4. **买方验收释放资金**: 买方确认系统正常运行，通知 Escrow.com 放款，资金秒级结算至个人账户。
