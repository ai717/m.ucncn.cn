# 🧠 MoneyLab 项目专属高价值 Skill 生产指导总纲 (Meta-Skill Guide)
> **适用对象**: Gemini 1.5/2.0 Pro、Grok 2/3、Claude 3.5 Sonnet、Antigravity 及本地 Agent  
> **核心使命**: 指导大模型自主阅读任意微型商业尽调项目，提取其独有的商业基因，产出**100% 个性化、零模板化套用、具备极高工程与商业密度的单项目专属 `SKILL.md` 交付资产**。

---

## ⚠️ 绝对禁令：杜绝“模板化套用” (Anti-Pattern Warning)

在生产单项目 `SKILL.md` 时，**严禁将单一项目的物料（如 Reddit 监听代码、冷发邮件模板）生搬硬套到其他不同形态的商业项目中**：
* ❌ **错误范例**：给一个“Chrome 插件出海”或“Notion 模板”的项目生成一套“Reddit 抓取 Python 脚本与冷邮件序列”。这是极其业余的千篇一律，会彻底摧毁付费用户的信任。
* ✅ **正确标准**：每个项目必须严格依据其独特的**交付载体、商业客群、变现路径与技术形态**，白手定制其独有的源码、Prompt 链、商务合同或运营物料。

## 🎯 第一部分：项目商业基因解剖与五大原型路由 (Archetype Routing)

当 Agent 拿到一个新的商业项目时，必须首先判定其归属于以下哪一类**核心商业原型**，并严格路由到该原型专属的资产结构：

```
                              [新项目尽调输入]
                                     │
         ┌──────────────┬────────────┴────────────┬──────────────┬──────────────┐
         ▼              ▼                         ▼              ▼              ▼
   【原型 A】       【原型 B】                【原型 C】       【原型 D】       【原型 E】
  B2B 获客监听    客户端浏览器扩展          AI 轻封装与企业服务    数字化虚拟资产   微型资产并购转手
 (Reddit/Twitter) (Chrome Extension)         (Shopify/RAG)       (Notion/小红书)  (Acquire.com)
```

---

### 原型 A：B2B 获客与强意向信号监听引擎 (Outbound & LeadGen)
* **典型代表**: Reddit 商业痛点监听器、Twitter 意向抓取、Apollo 潜客自动化挖掘。
* **核心商业机制**: 在潜在买家公开抱怨竞品或寻求替代工具的瞬间，以极低成本捕获信号并执行同行共情触达。
* **专属交付资产（必须包含）**:
  1. 目标社区阵地画像与三阶买意关键词（绝望型 / 明确预算型 / 痛点型）及负向噪音正则；
  2. 免 API 权限的自愈型数据监听源码（含 429 退避与原子去重）；
  3. Claude 3.5 / DeepSeek 0~100 分量化打分 Prompt 链；
  4. 实测 40%+ 打开率的 3 轮冷发邮件/私信追击话术（Permission-to-Demo、免费排坑模板、优雅断联）；
  5. 域名防封控体系（SPF、DKIM、DMARC、预热节奏）与 $5 零成本运行基建。

---

### 原型 B：客户端实用工具与浏览器插件 (Client-Side & Browser Extensions)
* **典型代表**: 垂直领域 Chrome 插件、桌面小工具、特定工作流剪藏器。
* **核心商业机制**: 依靠 Chrome Web Store (CWS) 庞大的自然搜索流量，以零服务器云端成本解决每天高频 15 分钟机械操作。
* **专属交付资产（必须包含）**:
  1. 完整的 Manifest V3 极简核心工程架构与权限最小化配置（防 Google 驳回）；
  2. Merchant of Record (MoR · 如 LemonSqueezy / Stripe) 许可密钥激活与离线缓存校验代码；
  3. Chrome 应用商店 SEO 标题与长尾搜索词布局矩阵；
  4. 解决特定场景单一高频痛点的核心 JavaScript 业务逻辑源码；
  5. 应对 Google 审核严苛政策的合规申报与隐私权限声明模版。

---

### 原型 C：垂直行业 AI 封装与企业私域助理 (AI Wrappers & B2B Solutions)
* **典型代表**: Shopify 独立站小语种本地化插件、本地律所/教培私域 RAG 问答机器人。
* **核心商业机制**: 传统企业缺乏技术团队部署大模型，愿为“减少客户流失、提高结账转化率”支付高额搭建费与月度维护费。
* **专属交付资产（必须包含）**:
  1. 解决特定垂直领域转化心理学的核心 Prompt 编排链（如电商本土化俚语润色、行业客服反幻觉防护）；
  2. 基于 Dify / FastGPT 或 Next.js 的企业专属架构 DSL 导出文件或 API 编排代码；
  3. 面向传统企业老板的高客单销售报价单、投入产出比（ROI）测算表与标准技术服务代运维合同；
  4. 向量知识库切片规范、敏感词拦截机制与零成本私有化托管方案。

---

### 原型 D：高审美数字化资产与虚拟情绪消费 (Digital Products & Virtual Assets)
* **典型代表**: Etsy / Gumroad 数字化 Notion 商业系统、小红书解忧杂货铺与情绪发卡。
* **核心商业机制**: 一次制作，无限售卖，零库存物流，95%+ 纯利润边际成本。依靠强烈审美与情绪共鸣实现冲动购买。
* **专属交付资产（必须包含）**:
  1. 包含复杂数据库联动与自动化公式的生产级 Notion 架构设计白模；
  2. Midjourney / NanoBanana 电影质感空镜与 iPad 商业样机渲染专属提示词套件；
  3. Etsy 13 个官方 SEO 标签卡位词表，或小红书引发强烈评论共鸣的“隐秘心理白描”爆款文案架构；
  4. 结合 Gumroad Webhook 或微信生态免扫码即时交付的自动化发卡与履约闭环协议。

---

### 原型 E：微型 SaaS 并购与高周转资产套现 (Micro-SaaS Flipping)
* **典型代表**: 72 小时 MVP 极速上线、验证初期现金流并在 Acquire.com 挂牌转让。
* **核心商业机制**: 避开长周期运营内耗，利用代码落地天赋将初期验证的现金流资产按 2.5x~3.5x ARR 溢价出售套现。
* **专属交付资产（必须包含）**:
  1. 72 小时内可一键上线的开源脚手架选型与 Stripe 订阅集成规范；
  2. 满足 Acquire.com 尽调的未脱敏财务 P&L 记账模板与获客漏斗数据审计表；
  3. 标准商业计划书（Pitch Deck）与挂牌转让标的描述模板；
  4. Escrow.com 资金托管协议、代码仓库交接与域名权限交割清单。

## 🏛️ 第二部分：双轨价值分流架构 (Free vs Paid Bifurcation)

为了兼顾**免费用户的极大吸引力**与**付费资产的超高价值**，必须严格执行以下信息分流原则：

| 维度 | 免费用户可见区（前端弹窗解锁区上方） | 付费用户解锁资产（专属 `SKILL.md`） |
| :--- | :--- | :--- |
| **商业机会与本质 (Core Thesis)** | **宏观洞察**：痛点成因、现有工具缺陷、商业套利空间、清晰的定性结论 | **操盘手人格**：打通该赛道的落地合伙人，输入“你好”提供 A/B/C/D 专属诊断 |
| **标准落地路径 (SOP)** | **4 阶段流程纲要**：阶段名称、核心目标、关键动作提示（大号字体、清晰友好） | **生产级工程资产**：可直接运行的代码、Prompt 链、配置文件与自动化脚本 |
| **量化评估指标** | 门槛星级、验证周期、启动成本、预估月现金流、四维进度条 | **未脱敏真实财务模型**：漏斗基准（抓取量/点击率/转化率/客单价/退款率/净利润率） |
| **运营物料与防坑** | 平台政策警戒、合规提示、核心技术栈标签 | **开箱即用物料**：真实销售信、合同协议、买点正则库、SEO 标签卡位表 |
| **后续演进能力** | 无（仅为静态阅读信息） | **AI 进化指令**：买家可直接命令其 Agent 基于该 Skill 自动拓展专属业务 |

## 🤖 第三部分：面向大模型 (Gemini / Grok / Claude) 的总提示词生成模板

当你（作为主调度 Agent 或用户）需要指挥另一个大模型（如 Gemini、Grok、Claude）为任意新项目撰写专属 `SKILL.md` 时，请直接将以下系统提示词喂给它：

```markdown
[System Instruction for AI Skill Generator]

你是一名拥有 10 年独立开发与微型资产并购经验的「全球轻资产变现商业总监兼首席架构师」。
你的任务是根据我提供的商业项目尽调信息，输出一份具备极高商业价值与可执行密度的专属【单项目高价值 SKILL.md 资产】。

【执行原则与质量红线】
1. 绝对严禁套用通用模板：严禁不顾项目实际形态，盲目复制其他项目的代码或话术。
2. 识别商业原型：
   - 如果是获客监听 -> 产出公开 JSON 监听脚本、意向打分 Prompt、3 轮冷发邮件；
   - 如果是 Chrome 插件 -> 产出 Manifest V3 架构、LemonSqueezy 许可证验证代码、应用商店 SEO；
   - 如果是 Shopify/RAG -> 产出电商转化 Prompt 链、Dify 编排配置、企业 B2B 维护合同；
   - 如果是 Notion/虚拟品 -> 产出数据库架构设计、Midjourney 样机提示词、Etsy 13 SEO 标签；
   - 如果是 Acquire 翻转 -> 产出 72 小时 MVP 规范、P&L 财报模板、Acquire.com 挂牌转让描述。
3. 注入操盘手激活协议 (Activation Rules)：
   用户在 Cursor / Claude Code / ChatGPT 中导入本 Skill 并发送“你好 / hello”时，Agent 必须立即唤醒为该领域的专属业务合伙人，并输出包含 A/B/C/D 四大交互式落地路径的欢迎语。
4. 提供真实单位经济模型精算 (Unit Economics)：
   必须给出具体的漏斗指标、转化率、客单价与月利润估算表。
5. 包含 Agent 自主扩展指南：
   给出 3 个让买家 Agent 基于本 Skill 自动为买家定制其专属业务的指令样例。

输出格式：符合标准 YAML Frontmatter 的完整 Markdown 文档，杜绝空话，100% 纯干货！
```
