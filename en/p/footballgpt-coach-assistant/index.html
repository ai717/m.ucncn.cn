🛠️ 4-Step Operational Blueprint (SOP)

➔ 阶段 01: 验证需求：找 10 个本地青训教练聊透备课痛点 - 访谈本地青训教练与俱乐部：每周备课花多久、愿为省时间付多少钱、现在用什么办法；扒足球教练论坛与 Trustpilot 差评，确认通用 AI 教案的短板；锁定一个年龄组（如 U12）先切入，不贪多。
➔ 阶段 02: Claude Code + Next.js/Supabase/Stripe 搭 MVP - 用 Claude Code 生成教案引擎（年龄组/人数/场地/主题四参数，输出结构化教案）；动画示意图先用静态图 + 文字走位描述起步；免费版限量 1 次用量；Stripe 接入周付与月付；本包 session_planner.py 可直接跑通教案生成与 MRR 推演。
➔ 阶段 03: 五档定价与流失挽留 - 定价 Free / Starter / Plus / Pro Weekly / Club 五档，Pro 周付 $2.99 起降低首次付费门槛；用量到限时提醒升级；到期前 3 天提醒续费；每月看 TrustMRR 的 MRR 与流失，及时处理差评。
➔ 阶段 04: 40+ SEO 页面 + 教练社群冷启动 - 按年龄组×主题×场地批量生成 SEO 落地页（如 U12 传球训练、U10 带球游戏），吃长尾搜索；去教练社群真实分享教案案例（不发广告）；给 3 家本地俱乐部免费整队试用一个月，换口碑与续费。
