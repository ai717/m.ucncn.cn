⚡ 研究团队尽调核心结论

定价本身就是广告：按邮箱收费的对手每月 $700 才够 100 个邮箱，它 $5 全包；但还没有收入实证，且有 $9/年的廉价对手在压天花板。

🔍 市场痛点剖析与商机本质

【真实市场痛点与供需断层】独立开发者每个副项目都买域名，但没有一个域名有邮箱。Google Workspace 按邮箱收费，每月 $7 一个，100 个邮箱就是 $700/月。DNS 记录（MX、SPF、DKIM、DMARC）是人人想拖的一步，转发到 Gmail 能收信却不能用域名回信。
【破局机制与商业套利切口】破局点是把“写 DNS + 建邮箱 + 发信”压成一句话：告诉 Agent 或跑一条命令，Cloudflare / Vercel / Porkbun 的记录自动写好，真实 IMAP/SMTP 邮箱建好，邮件经 Amazon SES 发出。$5 包月对 $700/月的按邮箱计价，价格本身就是广告。

🛠️ 4 阶段落地实施 SOP

阶段 01 · 先验证自动写 DNS 再卖 逆向洞察

去 Product Hunt 评论与 X 上找“每个域名都没有邮箱”的抱怨，确认买家是手里有 3 个以上域名的人，不是只有一个域名的用户。在 Cloudflare、Vercel、Porkbun 各测一个域名，从建邮箱到收到第一封回信全程跑通。

🏁 阶段交付物:3 家服务商的 DNS 实测记录 + 1 页买家画像
阶段 02 · 只做收信、发信与 DNS 三件事 极速构建

最小版本只做三件事：自动写 DNS、建 IMAP/SMTP 邮箱、经 SES 发信。不要做群发与冷邮件。新账号每天限发 50 封防滥用。提供 CLI 与 MCP 入口，让 Agent 能替用户跑“plainmail add hello@域名”。

🏁 阶段交付物:可用的邮箱服务 + CLI/MCP 入口 + 每日 50 封上限
阶段 03 · 一个价，Stripe 收第一笔钱 商业闭环

只卖一个价：$5/月包 50 个域名、100 个邮箱、25GB。GitHub 注册，随时取消。扣掉约 5% 的 Stripe 手续费与每月约 $30 的托管与 SES 成本，80 个用户净赚约 $340/月，240 个用户约 $1,090/月。不要学按邮箱收费，那正是你要打败的对手。

🏁 阶段交付物:Stripe $5/月订阅与首单
阶段 04 · Product Hunt 上线，盯紧廉价对手 渠道冷启

在 Product Hunt 上线，标题就写价格与套餐。去独立开发者社区问大家手里有几个域名、现在怎么收信。盯紧 FranklyMail（$9/年、无限邮箱与域名，约 Plainmail 价格的 1/7）：你的卖点必须是更稳的 SES 送达率、MCP/Claude 集成与持续维护，不是价格。

🏁 阶段交付物:Product Hunt 上线 + 80 个付费用户目标

⚠️ 避坑警戒与防范底线

注意三点：第一，FranklyMail $9/年无限邮箱域名，价格只有 Plainmail 的约 1/7，天花板压得很低；第二，新账号每天限发 50 封，定位是人与人之间的邮件，不是群发与冷邮件，别跑偏；第三，目前没有任何收入实证，$340~$1,090/月是按用户数算的模型，不是实测。
