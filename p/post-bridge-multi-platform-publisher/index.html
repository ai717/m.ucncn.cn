Tier C · 63 / 100 pts

Post Bridge 式一键多平台分发：写一次，全网发，API/MCP 让 AI 代发

一人公司做的跨平台分发 SaaS：写一次内容，一键发到 Instagram、TikTok、YouTube、X 等多平台多账号，按账号数收订阅费（Marketer 套餐 39 美元/月起，15 个账号）；另有 REST API、CLI 与 MCP 服务器，让 AI 直接代发。TrustMRR Stripe 验证 MRR 约 48,500 美元、累计收入约 58.2 万美元、约 1,600 订阅。

🔍 市场痛点剖析与商机本质

【真实市场痛点与供需断层】做短视频/做产品的创作者每天要把同一条内容手动复制到 Instagram、TikTok、YouTube、X 等多个平台：每个平台格式、标题、封面要求都不一样，光复制粘贴就要花近 1 小时；现成排期工具又贵又臃肿，小创作者用不上。时间全耗在重复发布上，没空做内容本身。
【破局机制与商业套利切口】只做'写一次，全网发'这一件小事：一个后台接多平台 OAuth，一次撰写按各平台规则自动适配标题、封面与格式；按账号数而不是按发帖量收费，定价简单好算；硬付费墙（无免费档）直接筛出愿意付钱的人；再把分发能力包成 REST API、CLI 与 MCP 服务器，让 AI 助手直接代发，踩中 2026 年 Agent 工作流的风口。创始人先给自己的应用做营销才顺手做出这款工具，需求是自己每天真实的痛，产品从第一天就贴合用户。

🛠️ 4 阶段落地实施 SOP

阶段 01 · 先拿自己的号做验证：连续 30 天每天多平台发一次 逆向洞察

自己先当第一个用户：每天把一条短视频手动发到 3~5 个平台，记下每步耗时与格式坑；访谈 10 个同样多平台发内容的创作者，确认他们愿为省时间付多少钱；只锁定'短视频创作者 + 一人公司'这一个客群，不做全能排期工具。

🏁 阶段交付物:30 天手动分发耗时记录 + 10 份创作者访谈 + 锁定的首发客群
阶段 02 · 一个月做出 MVP：多平台 OAuth + 一键分发 + 硬付费墙 极速构建

用 Supabase + Vercel + Trigger.dev + Unkey 搭后端（创始人同款低成本栈，月成本可控在 2,000 美元内）；先接 X、Instagram、TikTok、YouTube 四个平台的 OAuth 与发帖接口；每平台单独做标题/封面适配（本包 postbridge_publish.py 可直接跑通文案适配与发布队列校验）；上线即硬付费墙，无免费档，Stripe 按账号数计费。

🏁 阶段交付物:可跑通的 MVP + postbridge_publish.py 脚手架实测通过 + Stripe 订阅闭环
阶段 03 · 按账号数定价 + API/MCP 让 AI 代发 商业闭环

定价按连接账号数（Marketer 39 美元/月起，15 个账号），付费档不限发帖量，降低用户算账成本；随后补 REST API、npm CLI 与 MCP 服务器，让 Claude/ChatGPT 能替用户排期发帖；把 API 调用量与账号数挂钩，防止被白嫖刷爆。

🏁 阶段交付物:定价页上线 + API/CLI/MCP 三件套跑通 + 用量计费防刷
阶段 04 · X 公开开发 + 短视频自带流量冷启动 渠道冷启

在 X 上公开晒收入与进展（创始人靠这招做到 1,600 订阅），每周发 3~5 条真实进展；用自己的短视频号每天发内容，顺带展示产品；上 Product Hunt 与 Indie Hackers 拿第一波曝光；前 100 个付费用户给创始价并拉群，换口碑与续费。

🏁 阶段交付物:X 公开开发节奏跑起来 + 首批 100 个付费用户

⚠️ 避坑警戒与防范底线

获客几乎全靠 X 一个渠道，平台算法或账号一旦出问题增长立刻停摆，复制者须从第一天就同时经营短视频与邮件列表两个后备渠道；各平台 API 政策（Meta、TikTok、Instagram）随时可能收紧或涨价，分发失败要有降级提示与重试队列，不能静默丢帖；单人运营意味着客服、开发、运维全在一人身上，订阅量上来后须先补客服流程再扩功能；约 1,600 订阅与 29,000+ 注册为创始人自述与快照数，引用时注明口径与日期；MRR 与累计收入以 TrustMRR 页面实时数为准，引用前复核。
