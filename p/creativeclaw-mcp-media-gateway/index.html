CreativeClaw：MCP 媒体网关，把多家生图/生视频模型收进 Claude 与 ChatGPT 一处调用

一人公司把 fal.ai 等多家生图/生视频模型聚合为 MCP 服务，用户在 Claude/ChatGPT 里一处调用、按点数付费（$10=1000 点永不过期），网关层做模型路由与品牌参数注入。

预估月流水

复制者早期务实区间 $300~$1,500/月流水（毛利须扣除上游模型成本，未披露前不得按利润计）；对标方近 30 天流水 $112,268 为流水非利润，不可直接套用

验证周期

2~4 周（网关 MVP 约 1~2 周，MCP 目录上架与支付另计）

启动资金壁垒

$100~$400（域名、服务器、上游 API 预付额度、支付通道）

上手复杂度

★★★☆☆

⚡ 研究团队尽调核心结论

真实收入可查但毛利不确定、高度依赖平台目录分发：MRR $14,900、近 30 天流水 $112,268 均为流水非利润，转售成本未披露，9 月 18 倍跳涨原因未明，适合观察切口而非照抄体量。

🔍 市场痛点剖析与商机本质

【真实市场痛点与供需断层】在 Claude/ChatGPT 里做图做视频的创作者与小团队，原本要逐个模型站单独订阅、来回切换、分别记账，品牌风格还得每次手动重述一遍；单点订阅叠加后月费高、闲置浪费多，且生成结果散落在各站无法统一管理。现有替代方案要么太贵（每家都订一遍）、要么太重（离开对话界面去各站操作），用户愿意为“一处调用 + 品牌一致性”付费，本质是为省切换时间和省重复订阅费付费。
【破局机制与商业套利切口】切口不在自研模型，而在网关层：把多家模型经 fal.ai 等正规 API 聚合为一个 MCP 服务，用户只充一笔点数（$10=1000 点永不过期、100 免费点试用），网关负责模型路由表、按次扣点、品牌参数注入与失败重试，团队版 $50/月起收协作溢价。TrustMRR 经 The AI Receipts 于 2026-11-21 核实：MRR $14,900、近 30 天收入 $112,268、累计约 $291,000，一人公司运营。必须写清三件事：第一，上述收入为流水非利润，转售第三方模型的成本与毛利未披露，毛利不确定，复制者须先算清单次生成成本再定点数价；第二，9 月收入约 18 倍跳涨原因未说明，不可假设可复制；第三，获客高度依赖 Claude/ChatGPT 目录分发，平台规则或目录排名变化即断流，抗风险稳定性仅 4 分。务实测算：单兵复制者早期更现实的是 $300~$1,500/月流水区间，且须扣除上游调用成本、支付手续费与退款后才是利润，严禁把对标方流水当复制者利润宣传。

🛠️ 4 阶段落地实施 SOP

阶段 01 · 锁客群与算清单次成本 逆向洞察

只服务在 Claude/ChatGPT 里高频做图做视频的创作者与 2~5 人小团队；逐项核对上游各模型的单次生成价格、失败是否计费、并发与商用授权，算出每点成本与毛利安全垫，毛利算不清不上线。

🏁 阶段交付物:客群一页纸 + 单次生成成本与点数定价表（含毛利不确定声明）
阶段 02 · 搭最小 MCP 媒体网关 极速构建

实现 /generate 端点：点数账户与扣减、模型路由表、品牌参数注入、上游调用适配层与失败退款；上游先接一家正规 API 跑通闭环，再扩模型清单，网关逻辑必须可独立运行自测。

🏁 阶段交付物:可运行的网关服务 + curl 自测通过的扣点与路由记录
阶段 03 · 点数支付与对账 商业闭环

接入正规支付通道卖点数包（对标 $10=1000 点永不过期、100 免费点），团队版按月收费；每笔扣点留流水、失败自动退点，每周对上游账单与点数收入，毛利为负的模型立即调价或下架。

🏁 阶段交付物:点数购买—扣减—退点—对账闭环与周对账表
阶段 04 · 目录分发与种子用户 渠道冷启

申请进入 Claude/ChatGPT 相关目录与 MCP 清单获取分发，同时在创作者社区用真实生成案例冷启 10~50 个种子用户；不把目录当唯一渠道，同步沉淀官网直购与社群，避免单点依赖。

🏁 阶段交付物:目录上架记录 + 首批种子用户与首笔点数收入

⚠️ 避坑警戒与防范底线

合规与避坑：收入为流水非利润，转售模型成本未披露、毛利不确定，不得用流水冒充利润；9 月跳涨原因未明，不得承诺可复制；高度依赖 Claude/ChatGPT 目录分发，须预留官网直购等第二渠道；只走 fal.ai 等正规 API 并核对各模型商用授权与内容政策，禁止套壳倒卖、共享账号与绕过上游计费；点数永不过期须预提未履约负债，失败生成必须退点并留痕。
