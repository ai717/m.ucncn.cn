【真实市场痛点与供需断层】用 Claude Code、Codex、Cursor 的开发者能做出能跑的功能，但产出的网站、幻灯片、图片和视频普遍不好看，自己手写 Skill 也解决不了审美问题。Anthropic 官方 Skill 库免费且有 186k 星，但杂乱无筛选，拿来没法直接用。

🛠️ 4 阶段落地实施 SOP

阶段 01 · 选一个垂直方向，先做 5 个成品 逆向洞察

不要一上来就搭全目录。选一个自己最懂的垂直方向，如 OG 图、落地页或发布视频。拆解近 30 天 X / YouTube 上该方向最好的作品，先亲手做 5 个成品，再谈卖 Skill。

🏁 阶段交付物:1 个垂直方向 + 5 个成品 + 1 份竞品定价表
阶段 02 · 把成品写成 SKILL.md 并全程跑通 极速构建

每个 Skill 用固定结构：先放成品图或视频，再给模板、脚本与分步说明，最后写清怎么改颜色、文案与版式而不翻车。每个 Skill 必须用 Claude Code 从零跑一遍，产出与原作并排对比，差太多就改 Skill，不要改截图。

🏁 阶段交付物:5 个可安装的 SKILL.md 包 + 每份成品对比页
阶段 03 · 免费库引流，付费墙只拦完整包 商业闭环
