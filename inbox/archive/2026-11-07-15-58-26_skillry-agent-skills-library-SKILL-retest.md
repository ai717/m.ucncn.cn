## 💻 模块三：生产级极简核心工程源码 / 数据库架构

一个 Skill 就是一个文件夹：`SKILL.md` + 模板 + 脚本 + 一张成品图。先跑通下面这个脚手架，再往里面填自己的第一个 Skill。

```bash
#!/usr/bin/env bash
# skillry-starter.sh — 生成第一个 Skill 的骨架并自检
# 用法：bash skillry-starter.sh og-image
set -euo pipefail
NAME="${1:-og-image}"
mkdir -p "skills/${NAME}/templates" "skills/${NAME}/scripts"
cat > "skills/${NAME}/SKILL.md" <<'EOF'
---
name: og-image
description: "让 Agent 为落地页生成高审美 OG 图的 Skill：先看成品，再按模板与脚本复刻。"
---

# OG Image Skill

## 成品先行
先在 `templates/` 里放一张你亲手做好的 OG 图成品，Agent 照着它学。

## 工作流
1. 读 `templates/finished.png`，拆解版式、字体、配色。
2. 按 `scripts/render.sh` 的参数生成新图。
3. 把新图与成品并排对比，差太多就改模板，不要改截图。
EOF
cat > "skills/${NAME}/scripts/render.sh" <<'EOF'
#!/usr/bin/env bash
# 占位渲染脚本：把参数写进清单，确认流程跑通后再接真实渲染器
set -euo pipefail
echo "render: $*"
echo "OK: render pipeline reached"
EOF
chmod +x "skills/${NAME}/scripts/render.sh"
cat > "skills/${NAME}/check.sh" <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
test -f SKILL.md
test -d templates
test -x scripts/render.sh
./scripts/render.sh --dry-run
echo "OK"
EOF
chmod +x "skills/${NAME}/check.sh"
echo "created skills/${NAME}"
```

自检命令（在生成的 Skill 目录里跑）：

```bash
bash check.sh
# 应输出 render: --dry-run / OK: render pipeline reached / OK
```

## 🎯 模块四：行业特化型 Prompt 编排链或商务备忘录

### Prompt 1：从成品反推 Skill（每次做新 Skill 先跑这条）

```text
你是我做 Skillry 式技能库的合伙人。先看这张成品图/视频，拆解三件事：
1. 版式与结构：画面分几块、信息层级怎么排；
2. 视觉语言：字体、配色、留白、动效节奏；
3. 可变参数：哪些地方换文案、换颜色、换尺寸不会翻车。
然后输出一份 SKILL.md：先放成品，再给模板与分步说明，最后写“改哪里会翻车”的禁区清单。不要只写“做一张好看的图”这种空话。
```

### Prompt 2：每周热点复刻帖（冷启动用）

```text
这周最火的产品是。用我已有的 Skill 给它做一支 40 秒发布视频概念片，
明确标注“非官方概念”。文案结构：第一句讲它为什么火，第二句讲视频里最抓人的一个镜头，
最后一句请读者贴链接，前 5 名免费做。不要吹成官方合作。
```

## 📈 模块五：安全合规、防封防踩坑与冷启闭环 SOP

### 红线

1. **不要拿峰值周算收入**：近 7 天日均 $288，比峰值周跌超 40%。对外只讲 Stripe 验证的 29 天 $10,913 与日均数，不讲“月入过万”。
2. **不要假装官方**：复刻热点产品必须明确标注“非官方概念”，不要用官方品牌名义宣传。
3. **不要照搬官方免费库**：Anthropic 官方 Skill 库免费且有 186k 星，卖的是筛选与成品质量，抄它没有意义。
4. **不要卖课**：这个模式卖的是 Skill 包与订阅，不是“教你赚钱”的课程。

### 72 小时 MVP 节拍器

| 时间 | 动作 | 交付物 |
| --- | --- | --- |
| 第 1 天 | 选 1 个垂直方向，做第 1 个成品 | 1 张成品图 + 拆解笔记 |
| 第 2 天 | 按模块三脚手架写出第 1 个 SKILL.md，全程跑通 | 可安装的 Skill + 对比页 |
| 第 3 天 | 创始人个人 X 账号发帖 + 挂 3 个导航站 | 首篇帖子 + 订阅链接上线 |

### 冷启动清单（前 10~50 个付费用户）

1. 创始人个人 X 账号首发，带“想要哪个 Skill 请留言”的钩子；
2. 免费视频库/成品库放主导航，单个 Skill 免费试用、不绑卡；
3. 挂 10~15 个中英文 AI 工具导航站；
4. 每周复刻一个热点产品，标注非官方概念；
5. 每周按日均收入复盘，不拿爆发周外推。
